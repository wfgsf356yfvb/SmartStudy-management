📘 Platform Docs

Documentation overview for the roles and workflows currently available in the PlaySchool platform.

Admin Guide

  • Manage users, fee structures, payment submissions, and announcements
  • Review reports, staff attendance, and student progress
  • Review private payment receipt files within authorized school workflows

Teacher Guide

  • Mark attendance and assign homework
  • Submit weekly reports and record student progress
  • Review submissions, grade work, and publish announcements

Student Guide

  • View attendance, homework, grades, and weekly progress
  • Submit homework and view teacher reference files
  • Review fee information and submit payment details with optional receipts

Security and operations

  • Tenant-aware routing and role-based authorization protect school workflows
  • Private uploads use tenant-scoped keys and authorized download routes
  • Super Admin provisioning, retry, audit, and recovery utilities are available; live production-service verification remains pending
