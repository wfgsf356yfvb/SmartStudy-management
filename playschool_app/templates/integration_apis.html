🔌 Integration Status

PlaySchool currently provides role-based web workflows for school operations. A public third-party API is not advertised as generally available.

Available application workflows

  • Tenant-aware school, user, attendance, homework, progress, and fee workflows
  • Announcements for school users
  • Protected receipt and homework file handling
  • Super Admin tenant provisioning and payment-review workflows

What is not currently advertised

Razorpay integration, verified webhook handling, and a public developer API are not currently complete features. Object storage and malware scanning are supported as configurable architecture, but real production verification is still pending.
